## 4. 숫자·문구를 실제 값으로 바꾸기 ⚠️ 필수

화면의 모든 수치는 **예시 플레이스홀더**입니다. 각 파일 상단 `CONFIG`만 고치면 됩니다.

| 파일 | 바꿀 값 |
|---|---|
| `scenes/01-timeline.html` | `rateStart`, `rateEnd` (65세 이상 비율 %) |
| `scenes/02-population.html` | 세 카드의 `to`(어린이집 폐관/어르신/독거) |
| `scenes/03-careworkers.html` | `total`(돌봄 종사자 수), `perIcon` |
| `scenes/04-budget.html` | `amountA`, `amountB`(억) — 금액을 비공개하려면 숫자만 빼고 문구만 둬도 됨 |
| `scenes/09·10-lower-*.html` | 인터뷰이 `name`, `role` (예: 김순자 · 우만동 주민) |
| `scenes/15-closing-logo.html` | 복지관/법인 이름, 로고 |

고친 뒤 다시 렌더(아래 5).

## 5. 다시 렌더하기

```bash
npm install                 # 최초 1회 (playwright + 폰트)
node render.mjs             # 전체 다시 렌더 → out/
node render.mjs 02          # 02-population 만 다시 렌더
node render.mjs title       # 타이틀 PNG 4개만
```
출력: 영상은 `out/*.webm`, 오버레이는 `out/*.png`.

## 6. CapCut에서 webm이 안 열릴 때 → MP4 변환

CapCut **데스크톱**은 webm을 대부분 임포트합니다. 모바일 등에서 거부되면, **본인 PC의 ffmpeg**로 변환하세요
(이 저장소의 ffmpeg는 코덱이 제한되어 webm까지만 만듭니다):

```bash
# 일반 ffmpeg가 설치된 PC에서
ffmpeg -i out/01-timeline.webm -c:v libx264 -pix_fmt yuv420p -crf 18 out/01-timeline.mp4
```
투명 PNG는 변환 없이 그대로 오버레이로 사용합니다.

## 7. Before/After 사진 넣기 (컷 51)

같은 위치·같은 앵글로 찍은 두 장을 아래 이름으로 넣고 다시 렌더하면 분할 화면에 자동 반영됩니다.
```
assets/before.jpg   (개선 전)
assets/after.jpg    (개선 후)
```
사진이 없으면 라벨 플레이스홀더로 모션만 확인됩니다.
